# Phase 2 — Courses (merged sections), smart import, lesson sync

**Spec:** `docs/superpowers/specs/2026-10-08-real-curriculum-design.md` §2 (read it fully — it is the requirements). Speed over ceremony: light tests (a few integration tests for the core paths), typecheck, lint, then commit.

## Decisions already made (follow them)
- **Schema** (one migration `courses_lessons`):
  - `Course { id String @id @default(cuid()); schoolId; subjectId; gradeLevel Int; createdAt; school, subject relations (Cascade from School, Restrict from Subject); classes Class[]; lessons Lesson[]; @@unique([schoolId, subjectId, gradeLevel]) }`.
  - `Class.courseId String?` (FK Course, SetNull) + `sectionLabel String?`.
  - `enum LessonKind { MATERIAL ASSIGNMENT }`, `enum LessonStatus { NOT_GAMIFIED GAMIFYING READY FAILED }`.
  - `Lesson { id; courseId (Cascade); fingerprint; kind; title; description String @default(""); materials Json @default("[]"); position Int @default(0); postedAt DateTime; archivedAt DateTime?; status LessonStatus @default(NOT_GAMIFIED); gamifyError String?; contentChangedAt DateTime?; createdAt; updatedAt @updatedAt; sources LessonSource[]; @@unique([courseId, fingerprint]); @@index([courseId, position]) }`.
  - `LessonSource { id; lessonId (Cascade); classId (Cascade → Class); classroomItemId; classroomUrl String?; @@unique([classId, classroomItemId]) }`.
  - Subject delete guard (Phase 1, `school-subjects.service.ts` remove) must also 409 when courses use the subject.
  - **Backfill SQL at the end of the migration** (generic, no demo-specific ids): insert one Course per distinct (schoolId, subjectId, gradeLevel) of existing Classes where both are not null (id = `'c' || substr(md5(random()::text || clock_timestamp()::text), 1, 24)`, `ON CONFLICT DO NOTHING`), then set `Class.courseId` from the matching course where null.
- **Permissions** (`packages/shared/src/permissions.ts`): new resource `'course'`; `Target.courseClassIds?: string[]`. Role table: DIRECTOR/ADMIN read+write; TEACHER read+write; STUDENT/PARENT read. `can()`: admin → true; teacher → `intersects(classIdsTaught, courseClassIds)`; student → read && `intersects(classIdsEnrolled, courseClassIds)`; parent → read && `intersects(childClassIds, courseClassIds)`. Add 2–3 unit tests.
- **Shared schemas**: `importClassesBody` becomes `z.union`-free: `z.object({ courseIds: z.array(z.string()).optional(), items: z.array(z.object({ courseId: z.string(), subjectId: z.string(), gradeLevel: z.number().int().min(1).max(12), sectionLabel: z.string().max(20).nullish() })).optional() }).refine(b => (b.items?.length ?? 0) + (b.courseIds?.length ?? 0) > 0)`; `setClassCourseBody = { subjectId, gradeLevel 1-12, sectionLabel? }`.
- **New Nest module `courses`** (apps/api/src/courses/): `CoursesService` with `findOrCreate(schoolId, subjectId, gradeLevel)` (validates subject belongs to school), `label(course, locale?)` not needed server-side (web derives), `mine(a)` (teacher: courses of taught sections; director/admin: all school courses; student/parent: courses of enrolled/children's sections) returning `{ id, gradeLevel, subject: {id,key,name,color,icon}, sections: [{ id, name, sectionLabel, studentCount, syncError, lastSyncedAt }], lessonCount, gamifiedCount }`, `get(a, id)` (same shape + `canEdit`), `setClassCourse(a, classId, body)` (teacher of section or admin; find-or-create course; updates Class.courseId/subjectId/gradeLevel/sectionLabel). Controller: `GET /courses`, `GET /courses/:id`, `GET /courses/:id/lessons`, `POST /courses/:id/sync`; `PATCH /classes/:id/course` (put on ClassesController or a small CoursesClassesController — your call). Course object-level checks via `actors.assert(a, action, 'course', { schoolId, courseClassIds })`.
- **AI task `parseCourses`** (apps/api/src/ai/tasks/parse-courses.ts, model 'fast'): input `{ courses: {id,name,section}[], subjects: {id,name}[] }` → output `{ items: { id, subjectId: string|null, gradeLevel: number|null, sectionLabel: string|null, confidence: number }[] }`. Prompt must handle English/Arabic/French names (e.g. "6A Math", "Grade 6 – Math – B", "رياضيات السادس ج", "Maths 6ème B", Arabic ordinal grades الأول..الثاني عشر). Mock = deterministic heuristic: grade = first 1–2 digit number 1..12 in name+section (or Arabic ordinal word), sectionLabel = single letter A–H adjacent to the grade digit or after a dash/“section”, subject = first subject whose en/ar name (or its first 4 letters, case-insensitive) appears in the name. Server drops suggestions whose subjectId isn't in the school list and grades outside 1..12; accept AI suggestion only when confidence ≥ 0.5.
- **ClassroomService changes**: `listCourses(a)` adds per-course `suggestion { subjectId, gradeLevel, sectionLabel, courseId }` (courseId = existing Course with same subject+grade) and the response adds `subjects` (school subjects) and `schoolCourses` (`{id, subjectId, gradeLevel}`); `import(a, body)` accepts `items` (preferred) or legacy `courseIds` (filled from suggestions; rows without subject+grade import with no course). After attaching sections, run lesson sync for each touched course (errors logged, not thrown).
- **Provider**: add `listLessons(t, courseId): Promise<ClassroomLessonItem[]>` where `ClassroomLessonItem = { id, kind: 'MATERIAL'|'ASSIGNMENT', title, description, materials: LessonMaterial[], alternateLink: string|null, creationTime: string }` and `LessonMaterial = { type: 'drive'|'youtube'|'link'|'form', id?: string, title: string, url: string, mimeType?: string|null, thumbnailUrl?: string|null }`. Google impl: page through `courses.courseWorkMaterials.list({ courseId, courseWorkMaterialStates: ['PUBLISHED'] })` and `courses.courseWork.list({ courseId, courseWorkStates: ['PUBLISHED'] })`; map `materials[]` (`driveFile.driveFile{id,title,alternateLink,thumbnailUrl}`, `youtubeVideo{id,title,alternateLink,thumbnailUrl}`, `link{url,title,thumbnailUrl}`, `form{formUrl,title,thumbnailUrl}`). Treat Google errors with status 403 and message containing "insufficient" / `ACCESS_TOKEN_SCOPE_INSUFFICIENT` like invalid_grant (`ClassroomAuthError`). Fake impl: fixture lessons per course in `fixtures/courses.json` (`lessons` array) — give `fake-8b-math` and `fake-8a-math` the SAME two lessons (same titles + same drive/youtube ids, different item ids) to exercise dedupe, plus one lesson only in 8a; mutable in memory like rosters.
- **Scopes** (`auth.service.ts` `CLASSROOM_SCOPES`): add `https://www.googleapis.com/auth/classroom.courseworkmaterials.readonly` and `https://www.googleapis.com/auth/drive.readonly`.
- **LessonSyncService** (in courses module): `syncCourse(courseId)` per spec §2 "Lesson sync": iterate sections with classroomCourseId, owner creds (same owner logic as `ClassroomService.syncClass`), skip Tajriba-created items (id in Mission.classroomCourseWorkId set, or any material url starting with `config.WEB_URL`), fingerprint = sha256(normalizedTitle + '|' + sorted material keys), upsert Lesson by (courseId, fingerprint) (update title/description/materials; if a READY lesson's content changed set contentChangedAt), upsert LessonSource by (classId, classroomItemId), delete LessonSource rows of that section not seen this run (only for sections that synced successfully), archive lessons with zero sources (un-archive when they reappear), recompute `position` by earliest postedAt (= min creationTime across sources) for non-archived lessons. Per-section auth errors → `Class.syncError = 'RECONNECT'`, continue. Returns `{ lessons, added, archived, reconnect: boolean }`. Cron: after `syncAll()` roster sync, sync each course with ≥1 linked section (in JobsService, try/catch per course).
- **Seed**: create courses for the demo classes (Grade 7/8/9 · Mathematics via findOrCreate-equivalent upsert on the compound unique), set `courseId`, `sectionLabel` ('B' for 8B, 'A' for 7A, 'B' for 9B).
- **Fixtures**: add two `'*'` courses `fake-6a-math` ("Grade 6 Math - A", section "6A") and `fake-6b-math` ("رياضيات السادس ب", section "") each with 2 new students (unique googleIds/emails) and the same one lesson — used to test grouping. Don't break existing tests (onboarding test expects `fake-8a-math` in the list and imports it with `{ courseIds }`).
